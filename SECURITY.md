# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them to Radix at security@radix.com with a description and steps to reproduce.

This covers vulnerabilities in the skills in this repository, such as a skill that could cause an agent to leak data or bypass access controls, and any sensitive information committed here by mistake.

For vulnerabilities in a Radix MCP server or product, use the same address.
